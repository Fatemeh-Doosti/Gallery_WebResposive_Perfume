## ✨ About

A fully responsive perfume gallery/blog built with pure **HTML5** and **CSS3**. This project showcases a beautiful card-based layout for displaying perfume articles and tutorials in Persian (Farsi). The design adapts seamlessly across **Desktop**, **Tablet**, and **Mobile** devices.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Responsive Design (Mobile-First)
- CSS Grid & Flexbox
- BEM Methodology
- Custom Persian Fonts
- CSS Variables

---

## 📱 Features

- ✅ Fully Responsive Layout
- ✅ Beautiful Card Grid System
- ✅ Persian (RTL) Typography
- ✅ Custom Category Tags
- ✅ Pagination Support
- ✅ Hover Animations
- ✅ Mobile-First Approach

## 🚀 Getting Started

   ```bash
   git clone https://github.com/Fatemeh-Doosti/Gallery_WebResposive_Perfume.git
   ```

2. Open `index.html` in your browser.

## 🖼 Open Graph / Telegram Preview

To enable rich link previews when sharing on Telegram, WhatsApp, or social media, the `<head>` section includes Open Graph meta tags. Make sure to update the `og:image` URL with your hosted preview image.
